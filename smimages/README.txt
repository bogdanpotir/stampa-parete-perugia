Questa cartella contiene tutte le immagini e gli asset grafici del nuovo sito StampaMurale.

IMMAGINI DEL SITO
Per ogni nome puoi usare uno dei formati:
.webp
.png
.jpg
.jpeg

Esempio:
image1.webp
oppure image1.png

Non serve cambiare il codice: il sito prova automaticamente i formati supportati.

SISTEMA LOGO
logo.svg = logo principale orizzontale con simbolo infinito + StampaMurale + PERUGIA · UMBRIA
logo-icon.svg = solo simbolo infinito, per favicon/social/avatar
logo-light.svg = versione bianca per sfondi scuri o gradient
logo-dark.svg = versione monocromatica scura per stampa/documenti
logo-compact.svg = simbolo + StampaMurale senza PERUGIA · UMBRIA

Il sito usa logo.svg come file principale. Se in futuro vuoi sostituire il marchio in tutto il sito, è sufficiente sostituire questo file mantenendo lo stesso nome.

STAMPA MURALE — IMAGE MAP
==========================
Cartella immagini: /smimages/
Nel codice si usa solo il nome logico (image1, image2, ...).
Il sito prova automaticamente: .webp, .png, .jpg, .jpeg.
Se non trova il file, mostra un placeholder.

LOGO
logo.svg = logo centrale del sito. Per cambiare logo in tutto il sito basta sostituire questo file mantenendo lo stesso nome.

FORMATO CONSIGLIATO
- Fotografie: WebP, qualità 80-90, lato lungo 2000-2600 px.
- Se hai già PNG/JPG puoi usarli senza cambiare il codice.
- Per trasparenze o loghi: SVG o PNG.
- Nomi file in minuscolo esattamente come sopra: image1.webp, image2.png, ecc.
